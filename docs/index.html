🎓 De Zéro à Héros : Créez votre propre site

Pas de panique ! Vous n'avez besoin d'aucune connaissance en code. Suivez simplement ces 6 étapes comme une recette de cuisine pour avoir votre propre application de révision.

Étape 1 : Le Passeport (Compte GitHub) 🆔

GitHub est le site qui va héberger vos cartes gratuitement. C'est votre "disque dur" sur internet.

  1. Allez sur github.com.
  2. Cliquez sur "Sign up" et créez votre compte (c'est gratuit).
  3. Validez votre email. C'est la base de tout !

Étape 2 : La Copie (Le Fork) 🍴

Vous ne pouvez pas modifier MON site, mais vous pouvez en faire une copie pour VOUS.

  1. Connectez-vous à GitHub.
  2. Allez sur mon projet : leitexper1/testleitnercodex.
  3. En haut à droite, cherchez le bouton "Fork" et cliquez dessus.
  4. Cliquez sur "Create fork".
  5. Important : Vous êtes maintenant sur votre page projet (votre copie). Gardez cet onglet ouvert ou mettez-le en favori. C'est ici que vous déposerez vos fichiers plus tard.

Étape 3 : La Fabrication (Local) 🛠️

Revenez sur cette page (l'outil où vous lisez ce guide). Vous allez travailler "localement" dans votre navigateur pour créer le contenu.

  1. Fermez ce guide et cliquez sur "Import / Export avancé".
  2. Créez vos cartes (Questions/Réponses/Images).
  3. Cliquez sur "Exporter en CSV".
  4. Le fichier se télécharge sur votre ordinateur (dossier Téléchargements). C'est votre "cartouche" de jeu.
  5. Renommez ce fichier (ex: HISTOIRE_Rome.csv) pour bien l'identifier.

Étape 4 : Préparation sur votre ordinateur 📂

Avant d'envoyer quoi que ce soit, organisez vos fichiers sur votre ordinateur en respectant scrupuleusement cette structure :

docs/ (Dossier principal)
├── HISTOIRE_Rome.csv (CATEGORIE_Nom.csv)
├── ELECTRO_Triphase.csv(pas d'accents
├── images_questions/ (Dossier OBLIGATOIRE)
│ └── chat.jpg
└── images_reponses/ (Dossier OBLIGATOIRE)
└── chien.jpg
💡 Astuce de génie pour les catégories :
Pour créer des dossiers dans le menu, utilisez le tiret du bas _ dans le nom du fichier.
• HISTOIRE_questions_blabla.csv se rangera dans HISTOIRE
• ELECTRO_quest_triphas.csv se rangera dans ELECTRO

⚠️ Règle d'or : Pas d'espaces, pas d'accents, pas de caractères spéciaux (comme :) dans les noms de fichiers !

Étape 5 : La Livraison (Vers le Fork) 🚀

Il faut maintenant envoyer votre fichier (qui est sur votre ordinateur) vers votre site (votre Fork GitHub).

  1. Retournez sur l'onglet GitHub de votre projet (créé à l'étape 2).
  2. Cliquez sur le dossier docs dans la liste des fichiers.
  3. En haut à droite, cliquez sur "Add file" puis "Upload files".
  4. Glissez votre fichier CSV (et vos dossiers d'images si besoin) depuis votre ordinateur vers la zone grise.
  5. Validez en cliquant sur le bouton vert "Commit changes".

Bravo ! Votre site personnel va détecter ce nouveau fichier et l'ajoutera automatiquement à la liste des paquets disponibles.

Étape 6 : L'Activation (GitHub Pages) 🌍

Dernière étape : obtenir votre propre adresse web (URL) pour partager votre site.

  1. Sur votre projet GitHub, cliquez sur l'onglet Settings (Paramètres) tout en haut.
  2. Dans le menu de gauche, cliquez sur Pages.
  3. Dans la zone "Branch", vérifiez que main est choisi, et changez le dossier de "/ (root)" vers /docs.
  4. Cliquez sur le bouton Save.
  5. Attendez 1 à 2 minutes puis rafraîchissez la page. Un lien apparaît en haut (ex: https://votre-nom.github.io/...). C'est votre site !
